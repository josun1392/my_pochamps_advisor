# Initial experimental policy/value artifact

This is a working first learned model, not a strong battle advisor. The default
guaranteed-first recommendation policy is unchanged. Loading is explicitly opt-in.
Use only locally trusted SB3 artifacts: SHA/version checks do not sandbox pickle.

`model.zip` contains MaskablePPO weights and optimizer state. `model.json` binds
its SHA256 to the encoder, public catalog, action contract and pinned engine.
`catalog.json` is a public Champions Dex projection, regenerated by
`tools/showdown_bridge/learning-catalog.cjs`; it contains no episodes or hidden sets.
Its upstream MIT notice is retained in `SHOWDOWN_LICENSE.txt`.

## Reproduce (PowerShell, Python 3.11)

Install the optional CPU learning dependencies without enabling a new default:

```powershell
uv sync --extra learning --dev
```

Use the existing externally installed Showdown checkout at
`942cda71d14bf0618bd57991708a2e2734b6daba` and its compiled `dist/sim`.
All runs below execute local native battles. They instantiate no public server
client and make no provider calls. Outputs must be new paths. Model stems are
used below; scripts save `.zip` and `.json` automatically.

```powershell
$engine = 'C:\path\to\pinned-pokemon-showdown'
$catalog = 'models/showdown_initial_v1/catalog.json'
uv run --extra learning python scripts/train_showdown_policy.py --checkout $engine --catalog $catalog --output C:\temp\learn1 --steps 2048
uv run --extra learning python scripts/train_showdown_policy.py --checkout $engine --catalog $catalog --output C:\temp\learn2 --steps 8192 --resume C:\temp\learn1.zip
uv run --extra learning python scripts/warmstart_showdown_policy.py --checkout $engine --catalog $catalog --source C:\temp\learn2.zip --output C:\temp\teacher --decisions 4096 --epochs 12
uv run --extra learning python scripts/warmstart_showdown_policy.py --checkout $engine --catalog $catalog --source C:\temp\teacher.zip --output C:\temp\critic --decisions 4096 --epochs 8 --value-only
uv run --extra learning python scripts/evaluate_showdown_policy.py --checkout $engine --catalog $catalog --model C:\temp\critic.zip --cases 64 --offset 64 --split unseen --output C:\temp\unseen.json
uv run --extra learning python scripts/verify_showdown_learning.py --checkout $engine
```

Exact parameter reproducibility requires the recorded dependency versions and
seed/platform. SB3 ZIP timestamps can change file hashes even for equal weights.
Resume restores optimizer state and starts fresh deterministic episodes; it is
not an exact continuation of a suspended rollout buffer. Native environment
checkpoints remain separately available through `ShowdownEnvironment.save/restart`.

## Optional UI

```powershell
uv run --extra learning python scripts/verify_showdown_learning.py --export-demo C:\temp\learned-demo.json
uv run --extra learning python main.py --showdown-checkout $engine --showdown-shadow C:\temp\learned-demo.json
```

The demo specifies hypothetical teams and item assumptions, not live facts.
Compatible observed-state reconstruction and current selection are still required.
The existing strategy panel displays a separate learned choice for each native
root. Native conditional samples remain available. Disable by removing
`learned_policy` from the shadow config, setting `enabled: false`, or calling
`MainWindow.configure_showdown_shadow()` to roll the entire optional path back.
Model load/inference errors preserve existing native and exact recommendations.

Policy probabilities describe **action selection**, never win probability. The
critic predicts uncalibrated discounted sparse return under this policy/curriculum;
it may exceed [-1,1] and is neither an exact guarantee nor a calibrated win rate.
No learned output affects default ranking or observed truth.

See `docs/learned_policy_initial_result_2026-10-12.md` for measured limitations,
held-out results, algorithm comparison and validation evidence.
