# Combined Action Recommendation Flow

`advisor_combined_action_recommendation` consumes one frozen prepared cycle,
projects move and switch danger evidence, and produces an application-owned
selected-action envelope. The existing client keeps the provider path exactly
for a selected Move. A selected Switch or unresolved equal Switch tie bypasses
the provider and uses bounded deterministic presentation.

Switch presentation identifies only the trusted target and, for lower proven
danger, says that immediate confirmed KO danger is lower under current known
information. It never calls a neutral, entry-incomplete switch safe or claims
matchup/survival. Equal switches remain unresolved; no slot rank is invented.

Provider schema remains move-only. Permission, switch candidates, danger, and
the selected action envelope are internal. The next prerequisite is trusted
observation capture/automatic restriction derivation, not provider selection.
