# Ability Switch Blockers v2

Frozen, post-freeze blockers now include Shadow Tag, Magnet Pull, and Arena Trap. All
require exact ability identity plus applicable/affecting authority and remain
block-only. Magnet Pull additionally requires trusted current Steel typing and
does not block Ghost or Shed Shell targets. Any confirmed blocker vetoes manual
permission; no blocker grants permission. Arena Trap consumes only exact
identity-bound frozen groundedness; the old side-scoped grounded context remains
excluded from hard legality. Provider and UI remain excluded.
