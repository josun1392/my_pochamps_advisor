# Ability Switch Blockers v2

Frozen, post-freeze blockers now include Shadow Tag and Magnet Pull. Both
require exact ability identity plus applicable/affecting authority and remain
block-only. Magnet Pull additionally requires trusted current Steel typing and
does not block Ghost or Shed Shell targets. Any confirmed blocker vetoes manual
permission; no blocker grants permission. Arena Trap is explicitly deferred:
the available groundedness evidence is side-scoped and unsafe for identity-bound
hard legality. Provider and UI remain excluded.
