# Independent TRAIN-domain development team source v1

This experimental coordinator source addresses exhaustion of the finite V8
TRAIN bank. It is not a training/evaluation adapter and grants no battle or
model-selection permission. The frozen Foundation/16K/A/B actors and Adam are
not loaded or updated. Existing 512-game outcomes are not analyzed again.

The source builder reuses `generate_team_batch` and the maintained native
full-domain generator (uniform eligible base/form choice, upstream/domain set
modes, bounded native retries). The pinned Champions M-C `TeamValidator` is the
sole legality authority. A separate validation-only command checks every raw
candidate and explicit negative fixtures; no Battle/reset/step is created.

One frozen plan fixes seed, candidate count, minimum admission, exclusion
assets and adjacent-index pairing. All accepted candidates are retained; no
performance-based selection, redraw, replacement or hypothetical battle label
is used. Generation repeats once with identical inputs to verify full output
equality. Re-entering an existing output refuses generation.

Exclusions contain maintained native banks, previous pilot team identities and
the 96/288 sealed source identity assets, never sealed outcomes. Canonical
complete-team identity ignores nicknames, team order and move-slot order;
joint species/moveset identity is an additional stricter exclusion. Original
roster and move order in generated assets remain untouched. Individual set
reuse is allowed and measured, including slot-weighted and unique-set rates.
No species-unseen, set-unseen or expert-team claim is made.

The SHA-bound candidate manifest stores team/pair/generation bindings and
native validation, admission, novelty and composition assets. `load_candidates`
rejects corruption, path escape, invalid authority, altered pairing and
inconsistent attestations. It provides no native scenarios or evaluation API.
Both `evaluation_approved` and `battle_execution_approved` must remain false.

Composition is compared descriptively to all 4,096 V8 TRAIN teams using
species, moves, abilities, items, nature, stat-point maximum and move count.
Total variation and Jensen-Shannon distances measure finite-source differences,
not distribution equivalence or competitive quality. The new source is not
silently declared to follow the old distribution.

Run only from an externally frozen source-only plan:
`python scripts/build_independent_development_teams.py --output <artifact-root>`.
Private complete sets, manifests, model references and runtime receipts remain
outside Git. Source admission for actual evaluation needs a separate T1 decision.
