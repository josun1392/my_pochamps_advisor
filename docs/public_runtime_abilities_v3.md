# Public categorical runtime abilities V3

The pinned format Dex registry has 321 canonical ability IDs. V3 preserves all
215 V1/V2 ability IDs and appends the other 106, sorted, starting at token218.
Simple is token293. The existing 9-bit transport and 512-row ability embedding
already fit all IDs; dimensions (15,576), tensor shapes and parameter count are
unchanged. Registry vocabulary includes abilities outside M-C initial set
legality (including other formats/CAP); the native TeamValidator still owns
legality. Vocabulary membership is never an opponent-set assumption.

V1/V2 catalogs/contracts remain immutable. V3 has its own catalog, token-map and
feature fingerprints. All features encode identically for existing public V2
identities. Strict V2-to-V3 tensor copy is allowed only with token-prefix/shape
checks and a fresh optimizer; compatible same-V3 resume restores Adam explicitly.
The matched study starts all four arms from PPO2477 weights with fresh Adam,
not the historical partial V2 treatment.

Only known IDs/valid native display spellings are accepted. Unknown remains1,
confirmed absence2, padding0. The canonical noability registry ID is a distinct
known token, not an inferred absence. Ambiguous names such as As One, malformed
IDs and out-of-registry identities fail closed. Unrevealed opponent ability,
hidden sets/requests and future RNG never enter actor or critic.

Native tests cover Simple Beam, Worry Seed, Role Play and own Skill Swap request
reconciliation. Existing state-v2 public projection and numerical V4 features
remain unchanged. Compound public activation messages and ability suppression
are not rewritten into a more complete battle state by this vocabulary change;
the same structured-projection limits remain explicit. All321 registry entries
are supported tokens, not proof every entry is reachable in legal M-C play.

Source-trainer encoding failures save only the actual player-visible view,
encoder identity, error and case ID in the external run directory for the
coordinator. No native checkpoint or hidden truth is logged or used as a label.
Failed owned workers cannot bypass timer/lock cleanup. Original models and the
guaranteed-first production recommendation remain unchanged.
