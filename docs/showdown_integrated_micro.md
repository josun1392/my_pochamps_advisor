# Public teacher integration and admission v1

Historical Foundation training, auxiliary prediction, public tactical inputs,
native rewards, GAE, optimizer restoration and policy classes stay unchanged.
The new consumer is explicit and off by default. It uses the existing masked
policy and Adam before collection of a fresh PPO rollout. Hypothetical teacher
targets never become executed-trajectory rows, native rewards or value targets.

`PublicInformationSearchTeacher.assess` accepts only the observation adapter's
player view. Episode/revision/seat/turn, complete view and mask hashes, native
35-action schema, source policy identity and learning time bind each decision.
Unknown root fields, privileged search dictionaries, stale bindings, illegal
probability mass, malformed targets and nonempty on-policy buffers fail closed.
The provider receives no native handle, opposing request, real hidden set, RNG,
Foundation distribution or future outcome. Structural validation alone does
not certify target quality: only a reviewed public evidence producer can do so.

## Current producer boundary

The existing `PublicBestResponseOpponent` supplies bounded public-only response
comparisons. Its neutral unknown modifiers, nominal damage/order/position
utility, uncertain move availability and incomplete residual handling are NOT
complete public native branch evidence. The admission provider therefore
abstains, including when the surrogate produces an action. Neither that action
nor its fallback becomes a supervised target. The older checkpoint-based
`select_from_search` remains fixed-hidden-state feasibility evidence and has a
different schema. It cannot enter this consumer.

`pilot_foundation_integrated_micro --contract ... --output ...` audits frozen
preserved TRAIN views only. It cannot start battles or train/evaluate models.
Zero admissible coverage yields `PUBLIC_TEACHER_COVERAGE_BLOCKED`; it must not
be bypassed using a heuristic, a copied Foundation action or a relaxed flag.
Actual public-hypothesis native branching is still unsupported, not silently
implemented by this surrogate. A subsequent reviewed producer would also need
predeclared disjoint TRAIN/held-out situations and a native quality gate.

## Consumer and validation scope

`apply_public_teacher_decision` in the maintained trainer calls the offline
legal-only cross-entropy consumer with the in-process provider. It applies a
bounded coefficient (default .01), existing global norm clip .5 and existing
Adam. There is no change to PPO's objective, mask, learning rate or rollout
settings. A teacher update is a separately recorded offline update and clears
the next observation; subsequent PPO must collect new old log probabilities.
There is no custom checkpoint subclass or automatic teacher resume. Historical
configs never call this opt-in helper.

The append-only single-writer micro ledger reserves every optimizer call before
mutation, including fixture checks. Caps: 1024 TRAIN starts, 16384 transitions,
256 Adam calls combined and 256 evaluation starts. Failed attempts are not
refunded. At historical 4x128 rollout, batch128, epochs4, 256 Adam calls allow
at most 8192 PPO transitions before reserving any teacher/fixture updates.

Pure tests cover information boundary, abstention, identity/mask/time binding,
illegal targets, old schema rejection, opt-out, nonempty buffer rejection and
durable budget exhaustion. An explicitly authorized opt-in test uses preserved
native input and one memory-only Foundation clone Adam call with a **synthetic
fixture target**. This proves gradient/optimizer/probability wiring only. It
does not establish a genuine teacher label, native action quality, learnability
or playing strength. No synthetic fixture may be included in a training dataset.

No native smoke or matched learning study is justified while producer coverage
is blocked. The narrow next requirement is a public-evidence-consistent native
hypothesis constructor with explicit uncertainty/abstention, rather than more
PPO transitions or relabeling privileged native branches.
