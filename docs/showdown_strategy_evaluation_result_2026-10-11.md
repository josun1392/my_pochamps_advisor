# Showdown 전략 평가 E2E 결과 — 2026-10-11

**PARTIAL / CONDITIONAL GO.** 명시적으로 켠 네이티브 조건부 평가 시스템은
실제 전략 버튼부터 결과 표시·해제까지 동작한다. 전체 기본 엔진/추천 전환이

  피벗 첫 요청은 완전한 턴이나 전체 행동 KO 확률을 의미하지 않는다.

  신뢰구간이 아니며 미완료를 패배로 계산하지 않는다.
- 기존 전략이 선택 가능 후보를 확정하지 못할 때는 opt-in v2만 별도의
  조건부 후보 계약으로 사용자 기술/벤치 의도를 평가한다. 실제 선택 가능성,

- 기존 Qt 전략 버튼/설명/중앙 후보 카드에 표본 근거를 표시. v2 실행은
  백그라운드 처리하며 원래 추천/정확 근거를 변경하지 않는다.
- 전체 캡처·세션·UI 기준·설정 세대가 달라지면 비동기 결과를 폐기.

## 성능

다른 회귀 테스트 실행을 마친 뒤, persistent worker를 사용해 측정했다.
실험값 생성은 별도 Python mechanics/RNG 구현 없이 native fork를 사용한다.
JSON 루트는 배치마다 한 번 직렬화하고 각 표본에서 새 객체로 복원한다.

| 조건 | 표본 | 반복 | warm 중앙값 / p95 | UI 전달 / cold E2E |
|---|---:|---:|---:|---:|
| 4 세트 × 2 상대 행동 × 4 내 행동 × 32 시드, 첫 결정 | 1,024 | 20 | 780 / 856 ms | 110 / 1,726 ms |
| 같은 32 조건 × 16 시드, 최대 32 결정 | 512 | 20 | 4,830 / 5,110 ms | 108 / 6,259 ms |
| 같은 32 조건 × 8 시드, 최대 128 결정 | 256 | 3 | 2,770 / 2,840 ms | 104 ms / cold 포함 별도 JSON |

긴 평가는 UI를 막지 않는다. 빠른 실시간 비교는 작은 horizon/seed 예산을
사용하고, 긴 후속 평가는 별도 확인에 적합하다. 128 결정 사례의 미완료 합계는
0이며 256 표본이 모두 종료했다. 이 결과도 특정 가정/무작위 정책의 추정이다.

재현 명령/설정 계약: `docs/showdown_strategy_evaluation_contract.md`.
실행 증명 및 벤치마크: `scripts/verify_showdown_strategy.py`.
측정 JSON과 예시 JSON은 외부 탐색 디렉터리에만 보관하고 Git에 넣지 않았다.

## 남은 범위와 T1 결정

1. 기본 guaranteed-first 순위와 일반 공격의 완전한 exact/보장 ledger는 기존
   소비자를 유지한다. 16 damage rolls나 한 seed를 전체 행동 확률로 바꾸지 않는다.
   이전 검증된 native 직접 회복/고정 피해/switch-entry exact 조건부 경계도 유지한다.
2. 역사적 sleep/freeze 카운터와 persisted replay는 버전 호환 경계대로 유지한다.
   불충분한 관측 history, 알려진 미지원 효과 또는 상태 충돌은 기존 소비자 또는
   native 경계의 fail-closed 처리에 남는다. 자동 상태 추측으로 보완하지 않는다.
3. 완전한 상대 세트·출전 구성·행동 가정은 명시적으로 제공해야 한다. 메타 전체를
   대표하는 calibrated prior, 최적 상대 모델, 강한 학습 policy/value는 미구현이다.
4. **T1 결정 필요:** 통계적 평가 입력을 기본 추천에서 어떻게 사용할지, 기존
   guaranteed-first와 어떤 관계를 둘지. 현재 실험 점수의 기본 활성화를 제안하지
   않는다. 엔진 기술 검증은 전략적 우수성이나 전체 production gate 통과와 다르다.

다음 권장 마일스톤은 이 재현 가능한 native decision grid로 held-out 상태에서
강한 기존/학습 rollout policy/value를 비교하고, 표본 수·탐색 한도 민감도와
기존 보장 우선 정책 대비 전략 품질을 오프라인 평가하는 것이다.
전체 RNG 열거기나 Python 대체 메커니즘을 만드는 작업은 필요하지 않다.
