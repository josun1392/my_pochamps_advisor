# Shadow Tag Switch Block Contract

Shadow Tag is evaluated only after request freeze. The canonical combined-action
envelope finalizes base candidates before cross-action projection. It consumes frozen ability
identity/applicability/interaction plus frozen self current type, item, and
ability. It is block-only: only complete non-Ghost, non-Shed-Shell,
non-Shadow-Tag evidence returns `confirmed_blocked`; missing evidence never
permits switching. Manual permission is resolved centrally and a confirmed
block vetoes manual permission. Reducer copies of exception authority are not
introduced. UI/provider/presentation remain unchanged.
